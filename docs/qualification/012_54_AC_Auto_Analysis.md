# 012_54 — AC Coupling and Automatic Analysis Configuration (partial candidate)

Base integration/v1.4.0 178213f33d0425121ad6cc4ec935a347b4ed9854. Main remains the v1.3.5 release branch; no release or COM changes.

This candidate implements an observed low-frequency one-pole AC-like transfer (not physical topology identification), preserving measured values and existing 012_52 frequency/consent policy. Model H(f)=G*j*f/(fc+j*f), real signed G; fc estimated from f*Im(H)/Re(H), requiring observed points on both sides of the pole, alternating fit/holdout samples, 5% pole stability, absolute 0.001 and relative 2% complex residual limits. These additional thresholds are provisional engineering heuristics requiring actual-file validation; they are not a standard or instrument uncertainty. The existing local model spread threshold is unchanged. The model residual is separately recorded, not substituted for legacy model spread. Missing DC is zero only for a qualified observed high-pass candidate; real contradictory DC remains blocked. Below the first measured sample the model is anchored continuously to the measured point; above it the existing interpolation is unchanged.

Analytic one-pole time constant and frame droop are reported. This is NOT a full long-pattern or baseline wander qualification. Existing periodic FFT remains; short frame warning is explicit. Coupling is UNDETERMINED outside the observed model, not a DC topology assertion. No claim of actual PHY, BER, or compliance.
