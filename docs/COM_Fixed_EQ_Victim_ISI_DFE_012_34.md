## Contract
`calculateComFixedVictimFromSource` replays the captured source and uses the typed 012_33 historical causal producer. It retains source hash, revision, selected victim, mapping and generations, exact EQ and mode-conversion identity. Case-specific settings add exact hexadecimal floating-point decision time and six taps, and length-prefixed hex identities for optional voltage calibration. Each case is labeled and uses independent absolute decision time, 13 times t+k*UI (-3..+9), UI=1/53.125e9 seconds. Phase is absolute time modulo UI (origin t=0 in the supplied spectral time coordinate); no automatic phase selection. Existing measured-band quadrature guards apply. Source owner still has to verify actual current workspace before publishing; a passed-in observed identity is not a live provider.

Uses `calculateCom120F8RectangularPulse` and `calculateComDfe` with a real case-bound provenance, not an impulse or invented pair identity. DFE uses existing source-audited continuous min/max coefficients; only +1..+6 are changed; residual h[k]-b[k]*h[0] with ideal past decisions. Raw cursor polarity is preserved; unchanged taps are copied exactly. Observed precursor/postcursor/total RSS and optional assumed uniform independent PAM4 RMS=sqrt(5/9)*RSS and absolute sum are not full-channel ISI or certified tail bounds.

The existing paired voltage API in 012_21 requires identical absolute time grids; do not relax it. The new path reuses its internal single-case validation and multiplication. Optional evidence must match the exact 012_33 source/settings identity and both EQ identifiers must equal the combined physical settings key. Wrong case, nonpositive/nonfinite scale, mismatched provenance or planes fail closed. Omitted evidence means no voltage result for that case. Explicit declared volts-per-unit-symbol scale is applied once, not victimPeakV or assumed Sdd21 voltage gain. DFE residual is not passed off as an uncompensated 012_21 pulse. No tail engine integration.
